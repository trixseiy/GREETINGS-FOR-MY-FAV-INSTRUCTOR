# Dear Sir Randy — A Scrapbook 📖♡

A creative and interactive **Teachers' Day digital scrapbook** dedicated to **Sir Randy**. This project is designed as a small web-based scrapbook with multiple pages containing messages, memories, lessons, and a Teachers' Day greeting.

## 🌸 Project Overview

This website presents a six-page digital scrapbook:

1. **Cover Page** – Introduces the scrapbook with a special note for Sir Randy.
2. **Thank You** – Expresses appreciation for his patience, guidance, and kindness.
3. **A Memory** – Provides a space for a teacher photo and a memorable moment.
4. **From the Heart** – Contains a heartfelt message of gratitude.
5. **Lessons to Keep** – Highlights meaningful lessons such as keeping trying, being kind, believing in yourself, and never stopping learning.
6. **Final Page** – Ends with a Happy Teachers' Day message.

## 📁 Project Files

```text
Dear-Sir-Randy-Scrapbook/
│
├── index.html
├── style.css
├── script.js
└── teacher-photo.jpg
```

### `index.html`

Contains the main structure and content of the scrapbook, including the six pages, navigation controls, teacher photo section, messages, and Teachers' Day content.

### `style.css`

Controls the visual design of the scrapbook, including:

* Colors and typography
* Paper and scrapbook effects
* Background decorations
* Polaroid photo design
* Buttons and page indicators
* Page transition animations
* Responsive/mobile layout

The design uses fonts such as **Caveat, DM Sans, and Playfair Display**.

### `script.js`

Controls the interactive page navigation. It handles:

* Previous and Next buttons
* Page indicators/dots
* Current page counter
* Keyboard navigation
* Teacher photo loading and error handling

The scrapbook can also be navigated using the **Left ← and Right → arrow keys**.

### `teacher-photo.jpg`

Place the teacher's photo in the project folder using the filename:

```text
teacher-photo.jpg
```

The photo is displayed on the scrapbook's **A Memory** page.

## 🚀 How to Run

1. Download or copy all project files into the same folder.
2. Make sure `index.html`, `style.css`, and `script.js` are together.
3. Add the teacher's picture and name it:

```text
teacher-photo.jpg
```

4. Open `index.html` in a web browser.
5. Use the **Previous** and **Next** buttons to navigate through the scrapbook.
6. You can also use the **←** and **→** keyboard keys.
